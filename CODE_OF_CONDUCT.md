# Code of Conduct

We want this project to be welcoming and useful for everyone.

## Expected behavior

Be respectful to other community members. Ask questions when you don’t understand something. Give constructive feedback.

## Unacceptable behavior

Harassment, discrimination, threats, or any other abusive behavior is not tolerated.

## Enforcement

If you violate this code of conduct, maintainers may remove your contributions or restrict access to the repository.

## Reporting

Please report issues to the repository maintainers via GitHub issues.
