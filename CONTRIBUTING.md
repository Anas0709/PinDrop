# Contributing

Thanks for your interest in improving **AI Study Assistant Overlay**.

## How to contribute

1. Open an issue to discuss what you’d like to change (bug report or feature request).
2. Fork the repo and create a branch for your change.
3. Submit a pull request with a clear description of the motivation and what you changed.

## Development

The backend lives in `src/backend/`.

- To install dependencies: `cd src/backend && npm install`
- To run the backend syntax check: `cd src/backend && npm test`

## Code style

Keep changes small and focused. Prefer readable code and meaningful commit messages.

## Reporting bugs

If something is broken, please include:

- Steps to reproduce
- Expected vs actual behavior
- Relevant screenshots/log output
